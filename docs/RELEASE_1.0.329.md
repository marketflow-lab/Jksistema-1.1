# JK Sistema 1.0.329

## Etiquetas do Mercado Livre

- Etiquetas do Mercado Envios Flex são vinculadas à lista de separação pelo número da venda, do pacote ou do envio, mesmo quando o PDF separa os dígitos com um espaço.
- Ao reprocessar um PDF gerado pelo JK no layout padrão, o módulo preserva as etiquetas e reaproveita os SKUs que já aparecem no rodapé.
- Quando o PDF traz um DANFE simplificado após a etiqueta, o número impresso na lateral e o código de barras usam a chave de acesso de 44 dígitos da nota correspondente.
