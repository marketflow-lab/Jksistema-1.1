# JK Sistema 1.0.154

- Toda versao publica passa a oferecer um `Setup` completo para instalacoes novas e recuperacao.
- O instalador completo inclui e valida o Microsoft Visual C++ Redistributable, o Python offline, as bibliotecas e o modelo Whisper.
- O perfil `app-update` continua oferecendo o pacote leve para computadores que ja possuem uma instalacao valida.
- O perfil `runtime-update` publica o `Setup` completo como origem da atualizacao automatica.
- A preparacao dos artefatos rejeita nomes, conjuntos de arquivos ou manifestos `latest.yml` divergentes antes da publicacao.

[Validacao desta versao](https://github.com/marketflow-lab/Jksistema-1.1/blob/v1.0.154/docs/RELEASE_1.0.154_VALIDACAO.md).

Publicacao pelo perfil `runtime-update`, com o runtime offline completo.
