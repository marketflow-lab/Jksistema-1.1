# JK Sistema 1.0.336

## Importações

- **Rastrear carga** consulta COSCO Shipping, CMA CGM, HMM e Yang Ming quando o armador não é reconhecido. O painel mostra quais portais localizaram a referência, quais não encontraram correspondência e quais estavam indisponíveis.
- **Atualizar posição AIS** e **Ver mapa AIS** podem abrir fontes públicas no navegador do JK quando a API de posição não está configurada.
- Embarques, listas e SKUs têm cabeçalhos atualizados. O detalhe do embarque exibe bandeiras, horários e rota, e as telas mostram a cubagem em m³.

Distribuição pelo canal `app-update`.
