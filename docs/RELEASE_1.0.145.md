# JK Sistema 1.0.145

- Os quadros "Dados rapidos" e "Orientacoes da IA para este SKU" agora aparecem ao lado direito do titulo da pergunta em telas largas.
- O alinhamento usa a propria linha do titulo, mantendo a data acima dos quadros e liberando mais espaco vertical para a pergunta.
- Em telas intermediarias e estreitas, os quadros continuam empilhados abaixo da pergunta, sem rolagem horizontal.
- Os dois HTMLs do modulo usam um novo identificador de cache para aplicar o layout atualizado imediatamente.

[Validacao desta versao](https://github.com/marketflow-lab/Jksistema-1.1/blob/v1.0.145/docs/RELEASE_1.0.145_VALIDACAO.md).

Esta versao e uma atualizacao pequena no perfil `app-update`; ela nao substitui o instalador completo usado em instalacoes novas.
