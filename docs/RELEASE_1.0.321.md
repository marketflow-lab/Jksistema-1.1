# JK Sistema 1.0.321

- Importações refaz consultas interrompidas por mudanças nos dados. A lista e o detalhe do SKU mantêm os dados salvos visíveis enquanto atualizam.
- Consultas simultâneas do mesmo SKU compartilham o cálculo. O custo posto reaproveita a lista validada e confere sua revisão antes de calcular.
- Etiquetas ordena pedidos e SKUs e organiza a lista de despacho de Mercado Livre, Shopee e TikTok. O download bloqueia cliques repetidos enquanto o arquivo é gerado.
- Favoritos agiliza a remoção de anúncios do ranking e usa o MLB salvo para coletar novamente um anúncio do Histórico.
