# JK Sistema 1.0.367

Atualização pequena do aplicativo pelo canal `app-update`.

- A Pesquisa de Mercado consulta até oito anúncios do mesmo vendedor ao mesmo tempo. Cada consulta usa sua própria janela e só abre as janelas necessárias para os anúncios pendentes.
- A Renovação Fixa mantém a sessão da loja durante a conferência em paralelo e repete as leituras de participação que falham temporariamente, com até três tentativas por consulta.
- Se a participação continuar inconclusiva, a cópia fica bloqueada. A tela mostra exemplos de MLBs e motivos, e o botão **Baixar relatório** exporta todas as pendências daquela tentativa.
