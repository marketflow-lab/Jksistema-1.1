# JK Sistema 1.0.318

- O detalhe do SKU em Importações carrega os dados do produto e calcula o custo sem esperar pelas consultas de anúncios.
- A última margem compatível permanece visível durante a atualização. Quando o preço, o custo, o anúncio ou a conta muda, apenas as margens afetadas ficam pendentes.
- As margens dos anúncios próprios podem aparecer antes das dos concorrentes. A reabertura do SKU reaproveita a análise quando a conta e os dados de cálculo continuam válidos.
