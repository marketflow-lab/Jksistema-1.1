# JK Sistema 1.0.144

- O modulo Perguntas mantem a resposta vinculada ao anuncio correto e concilia as evidencias explicitas do anuncio antes da resposta final.
- A geracao com IA deixa as demais lojas disponiveis para leitura durante o processamento.
- Os contadores das lojas ficam na parte superior dos cards e o layout passa a se adaptar melhor a janelas menores, com rolagem nas areas extensas.
- O quadro "Atalhos de decisao" foi removido do detalhe das perguntas.
- A distribuicao desktop passa a oferecer uma atualizacao leve do aplicativo, reutilizando o runtime local somente depois de validar seu contrato e seus hashes.
- O lancador do empacotamento usa diretamente a CLI JavaScript do Electron Builder, com compatibilidade para Windows e Linux.
- A publicacao do desktop e executada pelo GitHub Actions com artefatos verificados antes da criacao da release.

[Validacao desta versao](https://github.com/marketflow-lab/Jksistema-1.1/blob/v1.0.144/docs/RELEASE_1.0.144_VALIDACAO.md).

Esta versao e uma atualizacao pequena no perfil `app-update`; ela nao substitui o instalador completo usado em instalacoes novas.
