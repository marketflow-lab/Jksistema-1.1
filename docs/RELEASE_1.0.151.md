# JK Sistema 1.0.151

- Perguntas sem uma variacao vinculada passam a mostrar todas as variacoes do anuncio.
- Cada variacao exibe seu nome, SKU e estoque atual, inclusive quando a quantidade e zero.
- Perguntas com uma variacao vinculada continuam mostrando somente o SKU selecionado.
- Os dados de variacao sao removidos do card quando o acesso ao anuncio e bloqueado, evitando a exibicao de informacao anterior.

[Validacao desta versao](https://github.com/marketflow-lab/Jksistema-1.1/blob/v1.0.151/docs/RELEASE_1.0.151_VALIDACAO.md).

Atualizacao pequena no perfil `app-update`, preservando o runtime existente.
