# JK Sistema 1.0.371

Atualização pequena pelo canal `app-update`.

- Em **Vendas**, os dados do mês corrente são consultados novamente ao reabrir o sistema.
- Em **Importações**, a importação de um pedido por Excel usa a loja selecionada.
- Em **Compartilhamento**, um novo envio manual recria o pacote quando o anterior já expirou, mesmo que os dados continuem iguais.
