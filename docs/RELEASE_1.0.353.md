# JK Sistema 1.0.353

Atualização pequena pelo canal `app-update`, com os ajustes aprovados de Vendas e navegação em abas.

- Move o período para a mesma linha dos filtros do gráfico de Vendas.
- Exibe apenas o mês e o ano no eixo mensal, sem o complemento de data do mês em andamento.
- Posiciona a seleção de loja virtual à direita das lojas.
- Reúne os controles de sincronização e a barra de status na mesma linha.
- Resume os status de progresso e atualização, preservando conferências, datas, contagens e erros em detalhes ou descrições acessíveis.
- Remove o aviso de cadastro legado acima do gráfico, preservando os metadados e os cálculos das composições.
- Permite usar Ctrl+clique para abrir telas em novas abas internas, preservando a origem, os filtros e os rascunhos.

Inclui as correções anteriores já publicadas até a versão 1.0.352. O `app-update` reutiliza o runtime compatível existente; o Setup completo acompanha a mesma release.
