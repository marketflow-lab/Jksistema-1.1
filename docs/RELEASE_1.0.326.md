# JK Sistema 1.0.326

- O TikTok processa etiquetas e listas no mesmo PDF. O rastreio vincula as páginas ao pedido e o resumo agrupa os itens por SKU.
- O resumo do TikTok lê o destinatário na etiqueta, inclusive nomes de uma só palavra como os que aparecem no campo em negrito.
- Os downloads preservam o nome original e acrescentam `E ` para etiquetas e `L ` para listas.
