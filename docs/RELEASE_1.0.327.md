# JK Sistema 1.0.327

- Em Médias e Pedidos e Vendas, clique com o botão direito na linha do SKU para adicionar, editar ou remover um comentário.
- Passe o mouse sobre o SKU para ler a observação. Os comentários ficam salvos por loja e aparecem nas duas telas.
- Para instalar em outro computador ou reparar o erro de runtime Python, baixe o **JK-Sistema-Cliente-Setup-1.0.327.exe**. Ele inclui o Python, as dependências e o Visual C++ exigidos pelo aplicativo.
- O atualizador automático usa o pacote **Update** em instalações com o runtime já validado.
