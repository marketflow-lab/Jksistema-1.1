# JK Sistema 1.0.347

Atualização pelo canal `app-update` com o novo layout aprovado de Perguntas e pós-venda.

- Cabeçalho ilustrado e fundos gráficos seguem a identidade de Vendas e Médias e Pedidos.
- Contas em cartões com ícones coloridos, seleção, conexão e contadores de perguntas.
- Conversas, dados rápidos e orientações por SKU com áreas mais legíveis e campo de texto escuro.
- Atalhos para Vendas, Médias e Pedidos e Home no cabeçalho.
- Configurações das contas em painel sobreposto, preservando o espaço da conversa ao abrir os controles.
- Ajustes para telas menores, com rolagem independente no desktop e conteúdo acessível no celular.

O pacote inclui o CSS e a ilustração do atendimento, com verificação de paridade com os arquivos-fonte.
O `app-update` reutiliza o runtime compatível existente. O Setup completo acompanha a mesma release.
