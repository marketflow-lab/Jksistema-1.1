# Vertex Gemini Mercado Livre Questions V2

This package isolates the new public pre-sale question flow from the legacy local AI flow and lets the backend plug in the existing Vertex Gemini caller.

Main modules:

- `MercadoLivreWebhookReceiver`: normalizes Mercado Livre webhook events.
- `QuestionFetcher`, `ListingFetcher`, `PreviousQuestionsFetcher`: adapter protocols for official Mercado Livre/API-backed data access.
- `QuestionClassifier`: classifies public pre-sale questions.
- `PolicyRouter`: decides Gemini, search + Gemini, or human review. Public answer text is not generated by deterministic templates.
- `SearchDecisionService` and `SearchService`: only use whitelisted domains.
- `PromptBuilder`: builds a prompt with the buyer question, listing link, research instruction, untrusted buyer text delimited, and a strict JSON output schema.
- `GeminiClient`: injectable client contract; in JK Sistema the backend wraps `_ia_agent_perguntas_chamar_modelo` so Vertex Gemini is used.
- `AIResponseParser`: parses the JSON answer contract.
- `AnswerValidator`: blocks unsafe content before any publish decision.
- `HumanReviewQueue`, `AuditLogger`, `MetricsService`: review, traceability, and counters.

Publication remains disabled by default:

- `AUTO_PUBLISH_ENABLED=false` means every valid draft goes to review.
- Invalid validation, low confidence, post-sale, regulated items, prompt injection, Gemini errors, and missing evidence always go to review.
- The current JK Sistema integration also keeps Mercado Livre direct sending behind the existing approval/sidebar flow unless an explicit direct-send environment flag is enabled.
- The JK Sistema Vertex call enables web search/grounding for public question V2 and sends a short query made from the buyer question plus the listing link.

Internal endpoints to expose later when this flow is split from `backend_api.py`:

- `POST /webhooks/mercadolivre`
- `POST /questions/{id}/process`
- `GET /questions/pending-review`
- `POST /reviews/{id}/approve`
- `POST /reviews/{id}/reject`

- `GET /metrics/ai-questions`

Mercado Livre note:

The current app already has OAuth-backed Mercado Livre helpers. New real API endpoints should be wired through adapters after checking the current official Mercado Livre documentation for the exact resource shape, authentication, status fields, and answer publication contract. Until then, adapter protocols keep this package testable without mutating real listings.
