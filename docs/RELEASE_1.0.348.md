# JK Sistema 1.0.348

Atualização pelo canal `app-update` com o layout antigo das telas de lista e detalhe do SKU de Importações.

- Dados e custos do pedido voltam a aparecer acima dos produtos.
- A lista usa a rolagem vertical da página, com todas as linhas disponíveis.
- A tela do SKU recupera a disposição anterior de Produto, Impostos e Custos e Análise.
- Cabeçalhos, cartões, cores e organização das duas telas seguem o layout da versão 1.0.335.

O pacote mantém as correções atuais de carregamento, custos e fotos dos produtos.
O `app-update` reutiliza o runtime compatível existente. O Setup completo acompanha a mesma release.
