# JK Sistema 1.0.331

## Perguntas

- **Excluir pergunta** remove a pergunta do Mercado Livre depois da sua confirmação. O JK atualiza a lista assim que o Mercado Livre confirma a exclusão.
- **Bloquear comprador** impede novas perguntas daquele comprador na conta que recebeu a pergunta. A ação também está disponível nas contas conectadas pela Central.
- **Estoque no Mercado Livre** mostra o saldo do anúncio em **Dados rápidos**, junto do SKU. O JK distingue saldo zero de saldo indisponível.

## Instalação

- O atualizador automático usa o pacote **Update** quando o ambiente local já está validado.
- Para uma instalação nova ou para reparar o ambiente Python, use o **Setup completo**.
