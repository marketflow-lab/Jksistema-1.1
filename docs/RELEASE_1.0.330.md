# JK Sistema 1.0.330

## Vendas

- O painel confirma a coleta do dia por loja antes de exibir **Atualizada** e mostra o horário da conferência.
- O gráfico recarrega após a gravação das vendas. Ao retomar uma loja, a fila prioriza o dia atual e preserva as pendências anteriores.
- Respostas incompletas do Bling deixam a coleta pendente para nova tentativa.

## Integração com o Bling

- A renovação do token é salva mesmo quando os dados da empresa são atualizados durante a renovação.
