# JK Sistema 1.0.372

Atualização pequena pelo canal `app-update`.

- Em **Integrações**, o limite do pacote completo de Cadastro passou para 128 MiB. A preparação reaproveita a seleção já salva e a prévia consulta apenas as pastas que podem conter os dados escolhidos.
- Em **Favoritos**, o botão de IA usa o Codex para preencher os três termos de pesquisa do produto.
- Em **Pesquisa de Mercado**, a consulta no Avant Pro volta a verificar anúncios pendentes, encerra a tentativa após três consultas e fecha a oferta de assinatura que interrompia a leitura. A pesquisa também identifica e ignora ofertas internacionais confirmadas.
